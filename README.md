# Calculator & Digital Clock Web Apps

A collection of interactive web applications built with HTML, CSS, and JavaScript.

## Projects

### 1. 🧮 Simple Calculator
A fully functional calculator with a modern interface and smooth animations.

**Features:**
- Basic arithmetic operations (add, subtract, multiply, divide)
- Percentage and decimal support
- Clear button to reset
- Delete button to remove last digit
- Modern gradient UI with hover effects
- Responsive design

**Open:** [Calculator](index.html)

---

### 2. 🌍 Digital Clock - Multiple Time Zones
A beautiful world clock displaying current time across 27 different time zones.

**Features:**
- 27 global time zones
- Main display with selected time zone
- Full date and day of the week
- Live updates every second
- Grid view showing all time zones simultaneously
- Time zone selector dropdown
- Beautiful gradient styling
- Fully responsive design

**Supported Time Zones:**
- **Americas:** New York, Chicago, Denver, Los Angeles, Anchorage, Honolulu, Toronto, Mexico City, São Paulo, Buenos Aires
- **Europe:** London, Paris, Berlin, Moscow
- **Asia:** Dubai, India, Bangkok, Shanghai, Tokyo, Seoul, Hong Kong
- **Africa:** Cairo, Johannesburg
- **Oceania:** Sydney, Melbourne, Auckland
- **UTC:** Coordinated Universal Time

**Open:** [Digital Clock](clock.html)

## How to Use

1. Clone the repository:
```bash
git clone https://github.com/mbillgatte-web/Calculator.git
cd Calculator
```

2. Open the desired HTML file in your browser:
   - `index.html` for the calculator
   - `clock.html` for the digital clock

## Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with gradients, flexbox, and grid
- **JavaScript (Vanilla)** - Pure JavaScript for interactivity and functionality

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

## Customization

You can easily customize these applications:

- **Colors:** Edit the gradient colors in the CSS files
- **Time Zones:** Add or remove time zones in `clock-script.js`
- **Styling:** Modify the CSS files to match your preferences
- **Functionality:** Extend the JavaScript for additional features
